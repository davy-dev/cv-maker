CV Maker
An AI-powered resume builder built with Next.js 16 and Claude AI. Paste a job posting URL, and the AI analyzes it against your profile to generate a perfectly tailored CV and cover letter — ready to edit and export as PDF.

Features
AI Job Posting Analysis — Scrape and analyze job listings to extract key requirements, then match them against your skills and experience using Claude AI
Tailored CV Generation — Automatically generate a CV optimized for each specific job posting
Cover Letter Generation — AI-crafted cover letters aligned with the job description and your profile
Real-Time Editor — Edit every section of your CV/cover letter with a live preview
PDF Export — Download your documents as professionally formatted PDFs with 4 template styles (Modern, Classic, Elegant, Minimalist)
Profile & Skills Management — Maintain your personal info, work experience, education, and skills in one place
Authentication — Secure login/registration with NextAuth.js
Tech Stack
Framework: Next.js 16 (App Router, React 19)
AI: Anthropic Claude SDK
Database: SQLite via Drizzle ORM
Auth: NextAuth.js v5
PDF: @react-pdf/renderer
Scraping: Cheerio
Styling: Tailwind CSS v4
Validation: Zod + React Hook Form
